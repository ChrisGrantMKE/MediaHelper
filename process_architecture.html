MODULE 01

Staging Dropzone & Intake Architecture

The ingestion engine monitors a single dropzone at \\CHRISGRANTS\files\Media\Music Albums\_INCOMING. When music is placed into this directory, INGEST_NEW_MUSIC.bat triggers the automated pipeline.

📋 Key Responsibilities

  • Scans all subdirectories and loose files inside _INCOMING.
  • Groups individual tracks into album bundles by parent folder path.
  • Prunes all non-playable clutter (.nfo, .sfv, .cue, .log, .m3u).
  • Guarantees _INCOMING is completely clean and empty after every run.

MODULE 02

Lossless Transcoding Engine (FFmpeg)

Standardizes all incoming lossless (.flac, .wav, .aiff, .ape) and container formats (.m4a, .ogg) into high-fidelity 320 kbps constant bitrate MP3s.

FFmpeg Transcoding Pipeline Code

def convert_to_320_mp3(src_filepath):
    ext = os.path.splitext(src_filepath)[1].lower()
    if ext == '.mp3': return src_filepath

    tags = read_and_clean_tags(src_filepath)
    out_mp3_path = f"{os.path.splitext(src_filepath)[0]}.mp3"

    cmd = [
        "ffmpeg", "-y", "-loglevel", "error",
        "-i", src_filepath,
        "-vn",
        "-c:a", "libmp3lame",
        "-b:a", "320k",
        "-ac", "2",
        out_mp3_path
    ]
    subprocess.run(cmd, check=True)
    write_tags(out_mp3_path, tags) # 100% tag preservation
    os.remove(src_filepath)        # Clean original source
    return out_mp3_path
MODULE 03

Acronym-Aware Casing & Name Inversion Engine

Guarantees that artist names retain standard Title Casing while automatically preserving acronyms without requiring manual dictionary entries.

🧠 Algorithmic Rules

  • Smart Acronym Preservation: Any uppercase word between 2 and 5 characters (RS, DJ, MC, BT, DVA, XL, FX, MF) is preserved as uppercase.
  • Non-Vowel 2-Letter Rule: Two-letter consonant pairs (dj, mc, rs, tv, uk) automatically uppercase to DJ, MC, RS.
  • Last, First Inversion: Automatically matches ^([A-Z][a-z]+),\s+([A-Z][a-z]+)$ and inverts to First Last (e.g. Yokota, Susumu $\rightarrow$ Susumu Yokota).
  • Honorifics Guard: Mr, Ms, Dr, St, Vs are capitalized rather than all-capped.

Casing Algorithm Implementation

def to_standard_title_case(name_str):
    minor_words = {'a', 'an', 'and', 'as', 'at', 'but', 'by', 'for', 'in', 'of', 'on', 'or', 'the', 'to', 'with', 'vs'}
    honorifics = {'mr', 'ms', 'dr', 'st', 'jr', 'sr', 'vs'}
    words = name_str.split(' ')
    title_words = []

    for idx, w in enumerate(words):
        w_lower = w.lower()
        if w_lower in honorifics:
            title_words.append(w.capitalize())
        elif w_lower in minor_words:
            title_words.append(w.capitalize() if idx == 0 else w_lower)
        elif len(w) == 2 and not any(v in w_lower for v in 'aeiouy'):
            title_words.append(w.upper()) # Acronym e.g. 'DJ', 'RS'
        elif w.isupper() and 2 <= len(w) <= 5:
            title_words.append(w)         # Preserve acronyms e.g. 'DVA', 'MDFMK'
        else:
            title_words.append(w.capitalize())

    return ' '.join(title_words)
MODULE 04

4-Layer Ambient & 2-Tier Genre Classifier

Resolves the historical issue where ambient music was cataloged as generic electronic by implementing a 4-layer taxonomy engine with ambient precedence.

🛡️ The 4 Classification Layers

Layer 1: Known Artists

Fast-path routing for premier ambient creators (Eno, Yokota, Budd, Lusine, Stars of the Lid, Basinski, etc.).

Layer 2: Keyword Net

Scans genre, album, and path for chillout, drone, soundscape, modular, field recordings, etc.

Layer 3: Precedence

Specific subgenres always beat generic parent buckets (Ambient beats Electronic).

Layer 4: CLI Fallback

Prompts you [1-6] for ambiguous/untagged releases instead of silently guessing wrong.

Classifier Implementation Snippet

def map_genre(genre_str, artist=None, album=None, filepath=None):
    # Layer 1: Check known artist catalog
    if artist:
        a_lower = strip_accents(artist).lower().strip()
        if a_lower in KNOWN_AMBIENT_ARTISTS:
            return "Ambient; Space Ambient" if any(k in a_lower for k in ["space", "tangerine dream", "schulze", "apollo"]) else "Ambient; Atmospheric"
        if a_lower in KNOWN_JAZZ_ARTISTS: return "Jazz; Fusion"
        if a_lower in KNOWN_CLASSICAL_ARTISTS: return "Classical; Contemporary Classical"

    # Layer 2: Expanded Keyword Net with Ambient Precedence
    context = f"{genre_str or ''} {album or ''} {filepath or ''}".lower()
    for keyword, mapped_2tier in GENRE_MAP.items():
        if keyword in context:
            return mapped_2tier # Ambient keywords evaluated first in dict order

    return None # Triggers interactive prompt rather than silent wrong guess
MODULE 05

Completeness & Quality Upgrade Evaluator

When an album being ingested already exists in the destination library, the engine compares track counts and bitrates to determine whether to upgrade.

Rule 1: Track Completeness

If incoming release contains more tracks (e.g. Deluxe Edition, Bonus Tracks, Complete Release vs Partial Rip), it automatically replaces the existing incomplete version.

Rule 2: Bitrate Quality

If track counts match, it audits audio bitrates. A 320 kbps MP3 will upgrade and replace older 128k, 192k, or 256k rips on the server.

MODULE 08

Deduplication Engine (unify_and_deduplicate_artists.py)

Scans all 6 libraries to detect duplicate folders, leading article variations (The Misfits $\rightarrow$ Misfits), foreign script aliases (מזמור $\rightarrow$ Mizmor), and runs 2-step Windows renames.

Two-Step Temporary Rename Implementation

def two_step_rename(parent_dir, current_name, desired_name):
    cur_p = os.path.join(parent_dir, current_name)
    des_p = os.path.join(parent_dir, desired_name)
    temp_p = os.path.join(parent_dir, f"__temp_unify_{re.sub(r'[^a-zA-Z0-9]', '', desired_name)}__")

    if not os.path.exists(cur_p): return
    for r, d, fs in os.walk(cur_p):
        for f in fs:
            if f.lower().endswith(('.mp3', '.flac', '.m4a')):
                update_tags(os.path.join(r, f), desired_name)

    if cur_p == des_p: return

    # Overcomes Windows case-insensitivity barrier
    os.rename(cur_p, temp_p)
    os.rename(temp_p, des_p)
MODULE 09

Jellyfin SQLite Ghost Record Purge Engine (clean_jellyfin_db.py)

Explains why Jellyfin retains global artist cards even after folders are merged, and how the SQLite cleaner removes all 0-song ghost records.

⚠️ Why Jellyfin Retains Ghosts

In Jellyfin, MusicArtist entities are stored in a global server-wide table (BaseItems) that is independent of individual library folders.

When audio files on disk are renamed or moved, Jellyfin links the songs to the new artist card, but never deletes the old artist record from the database. Removing and re-adding libraries does not clear them.

Database Purge Query

# 1. Scans BaseItems for all active audio tracks
cur.execute("SELECT DISTINCT Artists, AlbumArtists FROM BaseItems WHERE type LIKE '%Audio%';")

# 2. Deletes any MusicArtist row not linked to active songs
cur.executemany("DELETE FROM BaseItems WHERE Id = ?", [(g_id,) for g_id in ghost_ids])

# 3. Compacts and optimizes SQLite database
cur.execute("VACUUM;")
